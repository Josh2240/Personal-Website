## Tech Stack

- **Frontend**: Next.js 14, React 18, TypeScript, Tailwind CSS
- **Backend**: Express, TypeScript, SQLite (better-sqlite3)
- **Auth**: JWT with 2FA support
- **Validation**: Zod
